# Local fonts

Inter and Playfair Display are bundled locally to keep builds independent of Google Fonts availability. These are the same Latin variable font files previously cached by next/font/google. Other scripts use the system font fallback.

Both font families are distributed under the SIL Open Font License 1.1; the original notices are included alongside the files.

Sources:
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
